📄 Analytical Application Documentation & Operations Manual
⚡ Step 0: Context Extraction Pathway
  • GZIP Stream Extraction Engine: Automatically handles native unzipping files using sequential byte-scans. Plain-text inputs are also detected and processed automatically.
  • Dynamic ID Filtering: Upload any custom gene/transcript list table (CSV/TSV/TXT) to isolate a specific subset of target matches. You can dynamically add or strip custom string identifiers.
  • Silent Injection: Transfers massive genomic records into evaluation textareas in under 0.1 seconds without triggering page freezing or confirmation dialog blockades.
🎯 Mode A: Discrete Contrast Analysis (Target vs Background)
  • Homer-like Model: Performs hypergeometric enrichment modeling to contrast target occurrences against baseline parameters.
  • Mann-Whitney U-Test: Computes non-parametric continuous frequency score distribution shifts across background pools.
  • Auto-Background Shuffling: If the control input field is left empty, the engine creates a matched background pool by shuffling your target arrays automatically.
📊 Mode B: Continuous Quant相関 Engine (DRIMust & Pearson)
  • DRIMust Model: Sorts the full dataset array dynamically by input expression fold-change columns and scans to find the optimal threshold partition score where motifs enrich.
  • Pearson Product-Moment: Models continuous dosage-response signals. Tracks frequency numbers directly against absolute continuous expression trends.
  • Clipping Cap: Sets an upper limit for high frequency occurrences to eliminate single out-of-bounds transcript row bias from skewing calculations.
🎻 Sub-Member Aggregation & High-Resolution Export
  • Core Sequence-Based Aggregation: Groups overlapping motifs (e.g., 6-mers) under their matching core sequences (e.g., 4-mers) to reflect real in vivo flexible binding patterns.
  • Sub-Member Summation: Clicking a clustered motif core dynamically sweeps your dataset and adds up the copy counts of all underlying variants for every gene row.
  • 300dpi Graphics Pipeline: Renders vector shapes onto a high-density canvas map, exporting sharp, presentation-ready PNG file copies instantly.
